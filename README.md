# Minecraft PE Reborn

A leaked source code of **Minecraft Pocket Edition v0.6.1**. Ported to macOS and Linux, with Android modernizations and infinite world support and a rediculous amount of extra features and modernisations.

**NOT FOR COMMERCIAL PURPOSES.**

---

## New features added in Reborn
- Full hunger system with sprinting.
- Even MORE Infinite world gen fixes
- All items in the game will now be forced to be shown in the creative invemtory
- More PC optimized, this port is ***NOT*** reccomended to play on a mobile device
- Much more optimized chunk generation (24FPS to over 800FPS on far setting)
- Fixed the sky randomly flashing when walking around
- Added tree decaying so the leaves on trees dont just float when broken
- Fixed trapdoor placement to work more like they do on Java Edition
- Made doors actualy drop items instead of dropping noting at all
- Fixed log placement so they rotate when placed at a certan angle like in modern minecraft
- Fixed a whole bunch of lighting bugs where whole chunks lighting just would not update
- Slim alyx style skin support so your able to use slim and normal skins (3 and 4 px skin support)
- And a bunch of other stuff that I genuinly forgot about
